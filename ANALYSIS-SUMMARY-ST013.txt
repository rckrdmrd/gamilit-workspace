2. REACT QUERY VS ZUSTAND DUAL-STORE PROBLEM
   ─────────────────────────────────────────

   Status: MITIGATED (Fixed 2026-03-02, but architectural issue remains)
   Severity: MEDIUM (User-facing, but edge cases)

   Data domain: ML Coins balance

   React Query (Header): GET /summary → 675 coins
   Zustand (Shop): localStorage → 175 coins (stale)

   Root cause: Two independent sources of truth
   - Header uses useUserGamification (React Query)
   - Shop uses useCoins (economyStore + localStorage)
   - No shared SSOT

   Fix applied (ShopPage.tsx, 2026-03-02):
   useEffect(() => { fetchBalance(); }, [fetchBalance]);

   Remaining problem:
   - WebSocket events invalidate React Query but not Zustand
   - After socket "coins_updated", header updates but shop doesn't
   - Manual refresh needed

   Sync rate: ~80% (covers 80% of scenarios)
