## Stack Tecnológico

- **Runtime:** Node.js 18+
- **Framework:** React 18 + Vite
- **Estado del servidor:** TanStack Query (React Query)
- **Estado del cliente:** Zustand
- **Estilos:** Tailwind CSS
- **Testing:** Vitest + React Testing Library
