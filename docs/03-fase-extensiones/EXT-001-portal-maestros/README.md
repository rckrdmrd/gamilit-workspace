## 🎯 Objetivo

Desarrollar un portal dedicado para maestros que les permita gestionar sus clases, estudiantes, actividades asignadas y monitorear el progreso individual de cada estudiante en tiempo real. Esta épica potencia la capacidad del sistema para soportar educadores como usuarios principales.

---

## 📦 Módulos Incluidos

- **Dashboard de Maestros**: Vista general de clases, estudiantes y métricas
- **Gestión de Clases**: CRUD de clases, asignación de estudiantes
- **Monitoreo de Progreso**: Visualización detallada de avance por estudiante
- **Asignación de Actividades**: Crear y asignar tareas personalizadas
- **Reportes de Desempeño**: Generación de reportes por clase y estudiante
