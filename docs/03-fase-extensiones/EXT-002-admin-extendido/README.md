## 🎯 Objetivo

Ampliar las capacidades del panel administrativo con herramientas avanzadas de gestión, configuración de parámetros del sistema, auditoría detallada y control granular de permisos y roles. Esta épica proporciona a los administradores del sistema el control total sobre la plataforma GAMILIT.

---

## 📦 Módulos Incluidos

**Funcionalidades Originales:**
- **Gestión de Usuarios Avanzada**: CRUD completo, estado de cuenta, historial de acceso
- **Control de Roles y Permisos**: Definición granular de permisos, asignación de roles
- **Configuración del Sistema**: Parámetros globales, temas, integraciones
- **Auditoría y Logging**: Registro detallado de acciones, trails de cambios
- **Dashboard Administrativo**: Métricas del sistema, salud de la plataforma

**Nuevas Funcionalidades v2 CORE (2025-11-08):**
- **Parametrización de Gamificación (US-AE-005)**: Configuración dinámica de parámetros de gamificación (XP, ML Coins, rangos Maya, ayudas) desde interfaz admin
- **Asignación de Grupos a Maestros (US-AE-007)**: Gestión de asignación de classrooms/aulas a maestros, asignación individual y masiva
