## 🎯 Objetivo

Implementar un sistema flexible de gestión de contenido educativo que permita a maestros crear, organizar y servir contenido multimedia (textos, imágenes, videos) asociado a actividades y cursos. Esta épica enriquece la experiencia de aprendizaje con recursos educativos variados y bien estructurados.

---

## 📦 Módulos Incluidos

- **Gestor de Contenidos**: CRUD de contenido, versionado, historial de cambios
- **Gestor de Media**: Upload y gestión de archivos, thumbnails, optimización
- **Librerías de Contenido**: Organización por categorías, etiquetas, búsqueda
- **Visualización de Contenido**: Embed de videos, renderizado de formatos múltiples
- **Distribución de Contenido**: Asociación con actividades, permisos, control de acceso
