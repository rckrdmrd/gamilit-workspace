## Stack Tecnológico

- **Runtime:** Node.js 18+
- **Framework:** NestJS
- **ORM:** TypeORM
- **Base de datos:** PostgreSQL 15+
- **Testing:** Jest
- **Documentación API:** Swagger/OpenAPI
