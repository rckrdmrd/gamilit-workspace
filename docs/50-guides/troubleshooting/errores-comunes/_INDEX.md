# Errores Comunes - Guía de Troubleshooting

## Contenido

Guía centralizada de errores frecuentes con soluciones organizadas por categoría.

## Subdirectorios

- `backend/` — Errores comunes en NestJS backend
- `database/` — Errores de PostgreSQL y DDL
- `frontend/` — Errores en React y TypeScript
- `integracion/` — Errores de integración entre capas
