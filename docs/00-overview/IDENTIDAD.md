# Identidad del Proyecto

> Definicion institucional y tecnica de GAMILIT.

## Contexto

GAMILIT es un proyecto `STANDALONE` en formato monorepo que integra codigo fuente, documentacion de producto y gobernanza de agentes en el mismo repositorio.

## Ficha rapida

| Aspecto | Valor |
|---------|-------|
| Tipo | STANDALONE |
| Repositorio | `git@github.com:rckrdmrd/gamilit-workspace.git` |
| Stack base | NestJS + React + PostgreSQL + Redis + Socket.IO |
| Estructura | `apps/`, `docs/`, `orchestration/` |
| Estado | Produccion activa (MVP) |

## Alcance del repositorio

- `apps/`: backend, frontend, database y scripts operativos.
- `docs/`: definiciones funcionales, tecnicas y operativas del producto.
- `orchestration/`: directivas SIMCO, perfiles de agentes e inventarios SSOT.
