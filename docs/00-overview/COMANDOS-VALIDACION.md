# Comandos de Validacion

> Comandos base por capa para validaciones tecnicas.

## Backend

```bash
cd apps/backend
npm run build
npm run lint
npm run test
```

## Frontend

```bash
cd apps/frontend
npm run build
npm run lint
npm run typecheck
```

## Database

```bash
bash apps/database/scripts/recreate-database.sh
```
