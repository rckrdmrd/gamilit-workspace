## Quick Reference

### Vision
GAMILIT (Gamificacion Maya para la Lectoescritura en Tecnologia) es una plataforma educativa que integra cultura maya con gamificacion para mejorar comprension lectora K-12.

### Modulos Educativos
1. **Comprension Literal** (5 ejercicios)
2. **Comprension Inferencial** (5 ejercicios)
3. **Comprension Critica** (5 ejercicios)
4. **Lectura Digital** (5 ejercicios)
5. **Produccion y Expresion** (3 ejercicios)

### Portales
- Estudiante (~100%) | Maestro (~95%) | Admin (~90%) | Padres (100%)

### Metricas
- 18 schemas, 171 tablas, 282 RLS policies
- 22 modulos, 850 endpoints, 833 tests
- 458 componentes, 85 paginas, 4 portales
