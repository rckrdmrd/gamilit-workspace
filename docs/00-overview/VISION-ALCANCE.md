## Vision del Proyecto

GAMILIT (Gamificacion Maya para la Lectoescritura en Tecnologia) es una plataforma educativa integral que transforma la experiencia de comprension lectora para estudiantes K-12 mediante la integracion de mecanicas de gamificacion inspiradas en la cultura maya.

La plataforma busca resolver el problema fundamental de la baja motivacion y engagement de los estudiantes en actividades de lectura tradicionales, ofreciendo un entorno interactivo donde el aprendizaje se convierte en una aventura gamificada.

---

## Objetivos Academicos

### Objetivo Principal
Mejorar la comprension lectora de estudiantes en niveles K-12 utilizando gamificacion como vehiculo motivacional.

### Objetivos Especificos
1. **Comprension progresiva:** Guiar al estudiante desde comprension literal basica hasta produccion critica
2. **Engagement sostenido:** Mantener motivacion mediante economia virtual, rangos y logros
3. **Seguimiento preciso:** Proveer metricas de progreso a maestros y padres en tiempo real
4. **Personalizacion:** Adaptar dificultad y contenido segun desempeno individual
5. **Inclusion cultural:** Integrar elementos de cultura maya como vehiculo tematico

## Sistema de Gamificacion - Cultura Maya

### Sistema de XP (Puntos de Experiencia)
- Puntos otorgados por ejercicio completado
- Multiplicadores por dificultad del ejercicio (1x, 1.5x, 2x, 3x)
- Bonificaciones por racha de dias consecutivos
- Bonificacion por completitud de modulo (100%)
- XP ajustado por calidad de respuesta (parcial/total)

### Rangos Jerarquicos Maya (5 Niveles)
Sistema de rangos inspirados en la jerarquia social maya:

| Nivel | Rango | Titulo Maya | XP Requerido |
|-------|-------|-------------|--------------|
| 1 | Iniciado | Ah K'in (Sacerdote) | 0 - 999 |
| 2 | Guerrero | Nacom (Capitan Guerrero) | 1,000 - 4,999 |
| 3 | Jefe | Batab (Jefe Local) | 5,000 - 14,999 |
| 4 | Gobernante | Halach Uinik (Gobernante) | 15,000 - 49,999 |
| 5 | Senor Supremo | Ajaw (Senor Supremo) | 50,000+ |

### Logros e Insignias
- Logros por hitos academicos (primer ejercicio, primer modulo completado, etc.)
- Insignias por consistencia (racha de 7, 30, 100 dias)
- Milestones por progreso en cada modulo
- Logros sociales (ayudar companeros, participar en equipos)
- Logros secretos (descubrimiento de easter eggs tematicos maya)

### Economia Virtual (ML Coins)
- **Moneda:** ML Coins (Maya Literacy Coins)
- **Fuentes de ingreso:** Ejercicios completados, misiones, logros, rachas
- **Tienda virtual:** Avatares tematicos maya, fondos de perfil, power-ups, efectos visuales
- **Power-ups:** Pista extra, tiempo extra, multiplicador de XP temporal

### Misiones
- **Misiones diarias:** 3 misiones que rotan cada dia (baja/media dificultad)
- **Misiones semanales:** 5 misiones de mayor alcance (media/alta dificultad)
- **Quests especiales:** Cadenas de misiones tematicas (cultura maya, eventos)

### Leaderboards
- **Por aula:** Rankings dentro del salon de clase
- **Por escuela:** Rankings a nivel escuela completa
- **Global:** Ranking general de toda la plataforma
- **Por modulo:** Rankings especializados por modulo educativo
- **Temporadas:** Reset periodico con recompensas de cierre

## Requerimientos Funcionales (RF)

### RF-01: Autenticacion y Autorizacion
- Login con email/password y OAuth 2.0
- Registro de usuarios con aprobacion de admin
- 4 roles: estudiante, maestro, admin, padre
- JWT con refresh tokens
- Sesiones multiples permitidas

### RF-02: Multi-tenancy
- Aislamiento de datos por escuela via RLS
- Cada escuela opera como tenant independiente
- Administracion centralizada de tenants
- Datos compartidos (contenido global) vs datos aislados (progreso)

### RF-03: Gestion de Contenido
- CRUD de lecturas con metadatos
- CRUD de ejercicios por tipo (23 tipos)
- Categorizacion por modulo, dificultad, grado escolar
- Versionado de contenido educativo
- Contenido global (admin) y contenido local (maestro)

### RF-04: Ejercicios Interactivos
- 23 tipos de ejercicios con motor modular
- Evaluacion automatica (modulos 1-4)
- Evaluacion manual (modulo 5 - produccion)
- Retroalimentacion inmediata
- Repeticion espaciada (spaced repetition)

### RF-05: Gamificacion
- Sistema de XP con multiplicadores
- 5 rangos jerarquicos maya
- Logros e insignias desbloqueables
- Economia virtual (ML Coins + tienda)
- Misiones diarias y semanales
- Leaderboards multi-nivel

### RF-06: Analytics y Reportes
- Tracking de progreso por estudiante
- Metricas de engagement (tiempo, frecuencia, completitud)
- Reportes para maestros (aula y por estudiante)
- Reportes para padres (progreso del hijo)
- Exportacion PDF/Excel

### RF-07: Notificaciones
- Notificaciones in-app (tiempo real via Socket.IO)
- Notificaciones email
- Notificaciones push (mobile)
- Notificaciones SMS (padres)
- Preferencias configurables por usuario

### RF-08: Real-time
- Leaderboards en tiempo real
- Notificaciones instantaneas
- Actualizaciones de XP y logros
- Estado de presencia de usuarios

## Requerimientos No Funcionales (RNF)

### RNF-01: Performance
- Tiempo de respuesta API < 200ms (P95)
- Render inicial de pagina < 1.5s
- WebSocket latency < 100ms
- Carga de ejercicio < 500ms

### RNF-02: Seguridad
- Row-Level Security (RLS) en todas las tablas multi-tenant
- JWT con expiracion corta (15 min) + refresh tokens
- Validacion de inputs en todos los endpoints (DTOs)
- CORS configurado por entorno
- Rate limiting (100 req/min por IP)
- Sanitizacion de contenido generado por usuarios

### RNF-03: Escalabilidad
- Multi-tenancy horizontal via RLS
- Stateless backend (horizontalmente escalable)
- Redis cache para datos frecuentes
- Connection pooling (PostgreSQL)
- Lazy loading en frontend

### RNF-04: Disponibilidad
- Target: 99.5% uptime
- Health checks activos
- Graceful shutdown
- Manejo de errores centralizado

### RNF-05: Usabilidad
- Mobile-first design
- Responsive design (mobile, tablet, desktop)
- Accesibilidad basica (WCAG 2.1 AA target)
- Soporte para lectura de texto-a-voz
- Interfaz adaptada para ninos (K-12)

### RNF-06: Mantenibilidad
- Arquitectura modular (22 modulos independientes)
- Cobertura de tests >= 80%
- Documentacion de API via Swagger/OpenAPI
- Inventarios actualizados por capa
- ADRs para decisiones arquitectonicas
