# Documentacion de Portales

> Manuales y especificaciones de los 4 portales diferenciados de gamilit.

## Portales

| Portal | Completitud | Descripcion | Directorio |
|--------|-------------|-------------|------------|
| [Estudiante](./student/) | ~100% | Dashboard, ejercicios, gamificacion, leaderboards | student/ |
| [Maestro](./teacher/) | ~95% | Gestion de aulas, asignaciones, reportes | teacher/ |
| [Administrador](./admin/) | ~92% | Gestion de contenido, configuracion, analytics | admin/ |
| [Padres](./parents/) | 100% | Vinculacion, progreso, notificaciones | parents/ |

## Estructura por Portal

Cada portal contiene:
- **PORTAL-{NAME}-GUIDE.md** — Manual completo del portal
- **specs/** — Especificaciones tecnicas (solo student por ahora)
- **Flujos** — Documentados en docs/30-ux-ui/flujos/
