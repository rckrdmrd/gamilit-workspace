# Inventarios - Documentacion Referencial

Este directorio contiene documentacion relacionada con inventarios especificos de features.

## Ubicacion Canonica de Inventarios

Los inventarios operacionales del proyecto se encuentran en:
```
orchestration/inventarios/
```

Inventarios disponibles:
- BACKEND_INVENTORY.yml - Inventario de modulos backend
- DATABASE_INVENTORY.yml - Inventario de objetos de base de datos
- FRONTEND_INVENTORY.yml - Inventario de componentes frontend
- MASTER_INVENTORY.yml - Inventario maestro consolidado
- SEEDS_INVENTORY.yml - Inventario de datos semilla
- TRACEABILITY_MATRIX.yml - Matriz de trazabilidad
- DEPENDENCY_GRAPH.yml - Grafo de dependencias
- TEST_COVERAGE.yml - Cobertura de tests

## Archivos en este directorio
