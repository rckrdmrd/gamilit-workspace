## Estructura de un Estandar

Cada documento de estandar debe seguir esta estructura:

1. **Metadata** - ID, titulo, estado, fecha, autor
2. **Problema Identificado** - Descripcion del problema que resuelve
3. **Estandar Definido** - Reglas y convenciones
4. **Guia de Implementacion** - Codigo de ejemplo y patrones
5. **Listado de Implementaciones** - Donde se aplica actualmente
6. **Checklist** - Pasos para nuevas implementaciones
7. **Referencias** - Links a documentos relacionados
