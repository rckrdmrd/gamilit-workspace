## 🎮 Gamificación

**Rangos Maya:** 5 niveles progresivos
- Ajaw (1.0x) → Nacom (1.25x) → Ah K'in (1.5x) → Halach Uinic (1.75x) → K'uk'ulkan (2.0x)

**ML Coins:** Moneda virtual ganada por:
- Completar ejercicios: 15 coins base
- Score perfecto: +6-12 coins
- Primer intento: +15 coins
- Streak diario: +2 coins/día
- Achievements: +25-200 coins
