## Módulos Educativos

### Módulo 1: Comprensión Literal

**Archivo:** `MODULO-01-COMPRENSION-LITERAL.md`

**Objetivo:** Identificar información explícita del texto: hechos, datos, fechas, nombres, eventos concretos.

**Mecánicas (5):**
1. Línea de Tiempo - Ordenar eventos cronológicos
2. Emparejamiento - Juego de memoria fechas/eventos
3. Verdadero o Falso - Evaluar afirmaciones
4. Completar Espacios - Fill-in-the-blank
5. Crucigrama Científico - Vocabulario científico

**Características:**
- 100% auto-gradables
- Dificultad: Fácil a Media
- Tiempo promedio: 5-10 minutos por mecánica

## Contenido Educativo: Marie Curie

### Temas Cubiertos

**Biografía:**
- Infancia en Polonia (Varsovia)
- Estudios en la Universidad de la Sorbona
- Matrimonio con Pierre Curie
- Vida familiar y balance con la ciencia
- Años finales y legado

**Descubrimientos Científicos:**
- Descubrimiento del Radio (Ra) y Polonio (Po)
- Teoría de la Radioactividad
- Trabajo con pechblenda
- Estudios sobre radiación

**Contexto Histórico:**
- Polonia bajo ocupación rusa (s. XIX)
- París como centro científico europeo
- Restricciones para mujeres en ciencia (1900s)
- Primera Guerra Mundial (unidades móviles de rayos X)
- Movimientos sufragistas

**Reconocimientos:**
- Premio Nobel de Física (1903)
- Premio Nobel de Química (1911)
- Primera mujer en ganar Nobel
- Primera persona en ganar 2 Nobels en diferentes categorías

**Legado:**
- Instituto Curie (París)
- Impacto en medicina (radioterapia)
- Inspiración para mujeres en STEM
- Consecuencias de la exposición a radiación

### Línea de Tiempo Principal

1. **1867** - Nacimiento en Varsovia, Polonia
2. **1891** - Ingreso a la Universidad de la Sorbona, París
3. **1895** - Matrimonio con Pierre Curie
4. **1898** - Descubrimiento del Polonio y Radio
5. **1903** - Premio Nobel de Física (compartido)
6. **1906** - Muerte de Pierre Curie (accidente)
7. **1911** - Premio Nobel de Química (individual)
8. **1934** - Muerte por anemia aplásica (exposición a radiación)

## Integración Backend

### API Endpoints Principales

```
# Módulos
GET    /api/modules                    - Lista todos los módulos
GET    /api/modules/:id                - Detalle de módulo específico
GET    /api/modules/:id/exercises      - Ejercicios de un módulo
GET    /api/modules/:id/access         - Verifica si desbloqueado

# Ejercicios
GET    /api/exercises                  - Lista ejercicios (con filtros)
GET    /api/exercises/:id              - Detalle de ejercicio
POST   /api/exercises/:id/submit       - Submit respuesta
GET    /api/mechanics/:id/hints        - Sistema de pistas

# Progreso
GET    /api/progress/user/:userId                   - Overview general
GET    /api/progress/user/:userId/module/:moduleId  - Por módulo
GET    /api/progress/attempts/:userId               - Historial
```

### Flujo de Submission

1. Frontend obtiene ejercicio (sanitizado, sin respuestas)
2. Usuario completa ejercicio
3. Frontend envía POST con respuestas
4. Backend valida respuestas server-side
5. Backend calcula score con multiplicadores
6. Trigger DB actualiza user_stats automáticamente
7. Backend chequea achievements desbloqueados
8. Backend verifica si usuario puede ascender de rango
9. Backend retorna resultado completo
