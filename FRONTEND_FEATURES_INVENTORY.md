## File Organization Patterns

### Types Files
Pattern: `*Types.ts`
- Located in `types/` subdirectories or alongside components
- Example: `verdaderoFalsoTypes.ts`, `economyTypes.ts`

### Schema Files
Pattern: `*Schemas.ts`
- Located in `schemas/` subdirectories
- Using Zod validation library
- Example: `authSchemas.ts`, `ranksSchemas.ts`

### Mock Data Files
Pattern: `*MockData.ts`
- Located in `mockData/` subdirectories
- Provide test data for components and API calls
- Example: `verdaderoFalsoMockData.ts`, `economyMockData.ts`

### Component Files
Pattern: `*.tsx`
- Located in `components/` subdirectories
- React functional components with TypeScript
- Multiple components per feature common
