                      PATRONES DE DISEÑO IMPLEMENTADOS
================================================================================

1. DUAL-TABLE PATTERN
   • exercise_submissions: Workflow (draft → submitted → graded)
   • exercise_attempts: Rewards (XP, coins, history)
   • Trigger automático al INSERT en attempts
   • Beneficios: Separación de responsabilidades, no duplicate rewards

2. UPSERT PATTERN (Base de Datos)
   • UPDATE user_stats si existe
   • INSERT con valores iniciales si NOT FOUND
   • Balance inicial de 100 ML Coins para nuevos usuarios

3. MAP-BASED LOOKUP (Backend)
   • O(1) performance en lugar de O(n²)
   • Evita N+1 queries problem
   • Batch fetch de todas las submissions

4. TRIGGER-BASED AUTOMATION (Base de Datos)
   • Event-driven updates automáticos
   • Atomic dentro de transacción
   • Exception handler para robustez

5. DEPENDENCY INJECTION (NestJS)
   • Módulos totalmente testeable
   • Constructor injection de servicios

6. CUSTOM HOOKS (React)
   • useModuleDetail, useModules
   • Encapsulación de lógica de fetch
