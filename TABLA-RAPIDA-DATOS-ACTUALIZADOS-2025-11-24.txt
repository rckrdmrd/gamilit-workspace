┌────────────────────────────────────────────────────────────────────────────┐
│ 4. FÓRMULAS DE CÁLCULO                                                    │
└────────────────────────────────────────────────────────────────────────────┘

XP GANADO:
├─ Base XP = score (0-100)
├─ Penalización: -10 XP por hint usado
├─ Fórmula: MAX(0, score - (hints_used * 10))
├─ Ejemplo: 85 - (2 * 10) = 65 XP
└─ Rango final: 0-100 XP por ejercicio

ML COINS GANADOS:
├─ Base coins = FLOOR(score / 10)
├─ Penalización: -2 coins por comodín usado
├─ Fórmula: MAX(0, FLOOR(score/10) - (comodines_used * 2))
├─ Ejemplo: FLOOR(85/10) - 0 = 8 coins
└─ Rango final: 0-10 coins por ejercicio

PROGRESS PERCENTAGE:
├─ Fórmula: (completed_exercises / total_exercises) * 100
├─ Ejemplo: (2 / 5) * 100 = 40%
├─ Rounding: Redondeado a entero
└─ Range: 0-100%

RANK PROGRESS:
├─ Fórmula: ((actual_xp - rank_min_xp) / (rank_max_xp - rank_min_xp)) * 100
├─ Ejemplo: ((1500 - 1000) / (3000 - 1000)) * 100 = 25%
└─ Range: 0-100%
