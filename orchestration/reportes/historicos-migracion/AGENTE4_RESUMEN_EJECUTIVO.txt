================================================================================
INTEGRACION DASHBOARD
================================================================================

Ubicación: /apps/student/pages/DashboardComplete.tsx

Flujo:
  1. Dashboard obtiene módulos vía useUserModules() hook
  2. Hook consulta API: GET /educational/modules/user/:userId
  3. Datos se transforman a formato ModulesSection
  4. Se pasan a <ModulesSection /> component
  5. Click en módulo → navigate(/module/:id)

Layout (grid 12 columnas):
  Fila 1: RankProgressWidget (4 col) | ModulesSection (8 col)
  Fila 2: EnhancedStatsGrid (4) | MissionsPanel (4) | RecentActivityPanel (4)

Módulos vistos en dashboard: ACTIVOS (no bloqueados)

================================================================================
API ENDPOINTS
================================================================================

Módulos:
  GET /educational/modules - Todos
  GET /educational/modules/:id - Uno específico
  GET /educational/modules/user/:userId - Del usuario
  GET /educational/modules/:id/exercises - Ejercicios

Ejercicios:
  GET /educational/exercises - Todos
  GET /educational/exercises/:id - Uno específico
  POST /educational/exercises/:id/submit - Enviar respuesta

Progreso:
  GET /educational/progress/user/:userId - General
  GET /educational/progress/user/:userId/module/:moduleId - Por módulo
  GET /educational/progress/user/:userId/dashboard - Stats dashboard
  GET /educational/progress/activities/:userId - Actividades
  GET /educational/analytics/:userId - Analytics

API Client:
  Base: http://localhost:3006/api
  Timeout: 30s
  Auth: JWT Bearer token + X-Tenant-Id header
  Interceptores: Request (token), Response (error handling, token refresh)

================================================================================
HOOKS PERSONALIZADOS
================================================================================

useUserModules:
  - Carga módulos específicos del usuario
  - Requiere autenticación
  - Retorna: modules[], loading, error, refresh()
  - Ubicación: /apps/student/hooks/useUserModules.ts

useModules:
  - Carga todos los módulos (general)
  - Retorna: modules[], loading, error, refresh()
  - Variante: useModuleDetail(id) para módulo + ejercicios
  - Ubicación: /shared/hooks/useModules.ts

useModuleAccess:
  - Control de acceso basado en BD
  - Valida: prerequisites, rango_maya_required, is_published
  - Retorna: isLocked, canAccess, lockReason, getAccessMessage()
  - Ubicación: /shared/hooks/useModuleAccess.ts

================================================================================
CONTROL DE ACCESO
================================================================================

El sistema usa useModuleAccess hook para validación dinámica:

Reglas de Bloqueo:
  1. Si NOT is_published → Bloqueado
  2. Si NOT completed_prerequisites → Bloqueado + mostrar progreso
  3. Si NOT has_required_rango AND NOT is_free → Bloqueado
  4. Si cumple todo → Disponible

Mensajes:
  "Este módulo aún no está disponible"
  "Debes completar 2 módulos anteriores..."
  "Necesitas rango Holcatte o superior..."

Rango Maya Hierarchy:
  mercenario (1) < guerrero (2) < holcatte (3) < batab (4) < nacom (5)
