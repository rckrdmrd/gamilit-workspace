## 🚨 GAP-004: Backend Build Errors

**Severidad:** 🟡 P1 (Media-Alta)
**Área:** Backend - Código TypeScript
**Impacto:** Backend no puede compilar, desarrollo backend bloqueado

### Problema

El build del backend falla con 5 errores TypeScript:

```bash
src/app.module.ts(9,28): error TS2307: Cannot find module './config/database.config'
src/config/index.ts(2,43): error TS2307: Cannot find module './database.config'
src/modules/teacher/services/reports.service.ts(10,26): error TS2307: Cannot find module 'exceljs'
src/modules/teacher/services/reports.service.ts(618,26): error TS7006: Parameter 'row' implicitly has an 'any' type
src/modules/teacher/services/reports.service.ts(618,31): error TS7006: Parameter 'rowNumber' implicitly has an 'any' type
```

### Causa Raíz

#### Error 1-2: database.config.ts faltante
**Archivos afectados:**
- `apps/backend/src/app.module.ts` línea 9
- `apps/backend/src/config/index.ts` línea 2

**Referencias:**
```typescript
// src/config/index.ts
export { default as databaseConfig } from './database.config'; // ❌ Archivo NO existe

// src/app.module.ts
import databaseConfig from './config/database.config'; // ❌ Archivo NO existe
```

**Archivos existentes en config/:**
```
src/config/
├── app.config.ts ✅
├── env.config.ts ✅
├── index.ts ✅
├── jwt.config.ts ✅
├── swagger.config.ts ✅
└── validation.config.ts ✅
❌ database.config.ts FALTANTE
```

#### Error 3: exceljs dependency faltante
**Archivo afectado:**
- `apps/backend/src/modules/teacher/services/reports.service.ts` línea 10

**Problema:**
```typescript
import * as ExcelJS from 'exceljs'; // ❌ Module not found
```

**Verificación:**
```bash
$ grep -i "exceljs" apps/backend/package.json
# ❌ Sin resultados - dependency NO instalada
```

#### Errores 4-5: Tipos implícitos en reports.service.ts
**Archivo afectado:**
- `apps/backend/src/modules/teacher/services/reports.service.ts` línea 618

**Problema:**
```typescript
// Línea 618
someArray.forEach((row, rowNumber) => { // ❌ 'row' y 'rowNumber' tienen tipo 'any' implícito
  // ...
});
```

## 🔧 SOLUCIONES PROPUESTAS

### Solución 1: Crear database.config.ts (P1 - Inmediato)

**Acción:**
Crear `apps/backend/src/config/database.config.ts` basado en TypeORM configuración estándar.

**Template sugerido:**
```typescript
// apps/backend/src/config/database.config.ts
import { TypeOrmModuleOptions } from '@nestjs/typeorm';
import { envConfig } from './env.config';

const databaseConfig: TypeOrmModuleOptions = {
  type: 'postgres',
  host: envConfig.database.host,
  port: envConfig.database.port,
  username: envConfig.database.username,
  password: envConfig.database.password,
  database: envConfig.database.name,
  entities: [__dirname + '/../modules/**/*.entity{.ts,.js}'],
  synchronize: envConfig.env === 'development',
  logging: envConfig.env === 'development',
  ssl: envConfig.env === 'production' ? { rejectUnauthorized: false } : false,
};

export default databaseConfig;
```

**Verificación post-fix:**
```bash
cd apps/backend
npm run build
# Debe pasar sin errores TS2307 en database.config
```

**Delegar a:** Backend-Developer
**Estimación:** 30 minutos

---

### Solución 2: Instalar exceljs dependency (P1 - Inmediato)

**Acción:**
```bash
cd apps/backend
npm install exceljs
npm install --save-dev @types/exceljs
```

**Verificación post-fix:**
```bash
grep "exceljs" package.json
# Debe mostrar:
# "exceljs": "^4.x.x"
# "@types/exceljs": "^1.x.x"
```

**Delegar a:** Backend-Developer
**Estimación:** 5 minutos

---

### Solución 3: Tipar explícitamente en reports.service.ts (P2 - Bajo)

**Acción:**
Modificar línea 618 en `apps/backend/src/modules/teacher/services/reports.service.ts`:

```typescript
// ❌ ANTES:
someArray.forEach((row, rowNumber) => {
  // ...
});

// ✅ DESPUÉS:
someArray.forEach((row: any, rowNumber: number) => {
  // ...
});

// O mejor, tipar correctamente:
someArray.forEach((row: ExcelJS.Row, rowNumber: number) => {
  // ...
});
```

**Delegar a:** Backend-Developer
**Estimación:** 5 minutos
