2. COMPARACIÓN DE ARQUITECTURA
================================================================================

ORIGINAL (Express):
  - Routing: Archivos .routes.ts con Router()
  - Controllers: Métodos en clases Controller
  - Database: Pool PostgreSQL directo
  - Type Safety: Services con tipos TS
  - Estructura: Modular por feature

ACTUAL (NestJS):
  - Routing: @Controller decorators
  - Controllers: Métodos con @Get/@Post decorators
  - Database: TypeORM + connection pooling
  - Type Safety: Entities + DTOs
  - Estructura: Modular + DI container

VENTAJAS NestJS:
  ✓ Mejor type-safety
  ✓ Mejor test support
  ✓ Mejor structure enforcement
  ✓ Built-in middleware system
