## COMO USAR ESTA TRAZA

### Para encontrar un archivo movido:

1. Busca el nombre del archivo en la tabla de mapeo
2. La columna "Nueva Ubicacion" indica donde se encuentra ahora
3. Usa la fecha de movimiento para contexto temporal

### Para actualizar una referencia rota:

1. Identifica el archivo fuente con la referencia rota
2. Busca la referencia en la seccion "Referencias que deben actualizarse"
3. Actualiza con la "Nueva Referencia" indicada

### Para buscar historicos de un tema:

1. Navega a `orchestration/reportes/`
2. Usa las subcarpetas por categoria:
   - `historicos/` - Reportes generales por fecha
   - `correcciones/` - Bugs y fixes aplicados
   - `implementacion/` - Reportes de desarrollo
   - `gaps/` - Analisis de gaps cerrados
   - `database/` - Changelogs de BD
