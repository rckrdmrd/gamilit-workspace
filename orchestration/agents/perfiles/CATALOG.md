# Catalogo de Perfiles de Agentes

> Catalogo de detalle derivado del mapa operativo.

## Proposito

Este archivo concentra descripciones extensas de perfiles para reducir carga en
`_MAP.md`, que debe usarse como entrada rapida de asignacion.

## Uso recomendado

1. Consultar primero `_MAP.md` para mapear tarea -> perfil.
2. Abrir este catalogo solo cuando se requiera detalle completo de un perfil.
3. Aplicar contrato full comun antes de ejecutar: `PERFIL-CONTRATO-TRANSVERSAL.md`.
