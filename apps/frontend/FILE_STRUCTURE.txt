INTEGRATION POINTS
================================================================================

┌─────────────────────────────────────────────────────────────────┐
│                                                                 │
│  User visits /login                                             │
│         ↓                                                       │
│  LoginPage renders                                              │
│         ↓                                                       │
│  LoginForm validates with loginSchema                           │
│         ↓                                                       │
│  Form submits → useAuth().login()                               │
│         ↓                                                       │
│  AuthContext calls authApi.login()                              │
│         ↓                                                       │
│  API returns token + user data                                  │
│         ↓                                                       │
│  Token stored in localStorage                                   │
│         ↓                                                       │
│  User state updated in AuthContext                              │
│         ↓                                                       │
│  Auto-redirect to /dashboard                                    │
│         ↓                                                       │
│  ProtectedRoute allows access                                   │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘

VALIDATION FLOW

┌─────────────────────────────────────────────────────────────────┐
│                                                                 │

│         ↓                                                       │

│  User types password                                            │

│         ↓                                                       │
│  User clicks submit                                             │
│         ↓                                                       │
│  Zod validates all fields                                       │
│         ↓                                                       │
│  Valid? → Submit to API                                         │
│  Invalid? → Show all errors                                     │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘

================================================================================
ROUTES OVERVIEW
================================================================================

Public Routes:
  /login                → LoginPage
  /register             → RegisterPage
  /forgot-password      → ForgotPasswordPage

Protected Routes (require authentication):
  /dashboard            → Dashboard (wrapped in ProtectedRoute)
  /profile              → Profile (wrapped in ProtectedRoute)
  /admin                → Admin (ProtectedRoute + role check)

Default Route:
  /                     → Redirect to /login

404 Route:
  *                     → Redirect to /login
